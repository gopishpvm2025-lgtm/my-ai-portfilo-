# My Portfolio — AI/ML Software Engineer

A responsive, creative-interactive portfolio starter built with Next.js App Router, TypeScript, Tailwind CSS and Framer Motion.

## Run locally

1. Install Node.js 20 or newer.
2. Extract this project.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

For a production build, run `npm run build` then `npm start`.

## Personalize before publishing

Search for `EDITABLE PLACEHOLDER` throughout `src/` and replace:
- `[Your Name]`, `[your.email@example.com]`
- GitHub and LinkedIn URLs
- Project repository/demo links
- Learning milestones and project results
- Resume file at `public/resume.pdf`

Project case studies intentionally describe suggested portfolio projects. Build and verify each project before presenting it as completed. Do not invent model metrics or claim unearned experience.

## Routes

- `/` — portfolio homepage
- `/projects/smart-expense-analyzer`
- `/projects/student-performance-predictor`
- `/projects/ai-document-assistant`

## Accessibility and motion

- Keyboard-accessible navigation and controls.
- Visible focus styles and semantic landmarks.
- Respects `prefers-reduced-motion`.
- Particle field is decorative and hidden from assistive technology.
- No cursor-following effects that interfere with touch or keyboard use.

## Deployment

Deploy the repository to Vercel or another Node.js-compatible host. Add your own domain and verify all links, resume download, mobile layout and project claims before sharing.
